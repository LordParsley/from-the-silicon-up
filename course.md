# From the Silicon Up

Welcome! This is a free course about how computers actually work. We start at the bottom, with a tiny machine you can watch thinking, and build upward from there.

No installation, no accounts, no prior programming needed. If you can open a link, you can take this course.

## How this course works

- Each lesson is interactive: read a little, predict what a program will do, then watch it happen.
- Exercises run in free browser-based simulators. Keep the lesson and the simulator in separate tabs, side by side if you have room.
- Answer boxes check your typed answers. They never grade the simulator, so be honest with yourself: run the program and look.

A laptop or desktop will be more comfortable than a phone.

## Before the Silicon

The big ideas, before any electronics: an adding machine built from marbles and gravity, what an algorithm is, which problems no machine can solve, and why a programme is just data. This is the first module.

0. [A machine that adds](https://liascript.github.io/course/?https://raw.githubusercontent.com/LordParsley/from-the-silicon-up/main/before-the-silicon/lesson-01.md) - build a marble-powered adding machine in your head, then meet the ideas that make computers universal. About 25-30 minutes.

## Little Machine

Meet the CPU one instruction at a time, using the Little Man Computer teaching machine. This is the second module.

1. [A computer you can watch](https://liascript.github.io/course/?https://raw.githubusercontent.com/LordParsley/from-the-silicon-up/main/little-machine/lesson-01.md) - move a number, add to it, store it, jump, decide, and repeat. About 30-40 minutes.
