# From the Silicon Up

A free course about how computers actually work, starting from the machine itself and building upward.

No installation and no accounts. Lessons are plain Markdown in this repository, rendered in your browser by [LiaScript](https://liascript.github.io/). Exercises run in free browser-based simulators.

## How to take the course

Each lesson is a Markdown file you can read right here on GitHub. For the full experience, with interactive answer boxes, open it through the LiaScript viewer instead: paste the lesson's raw GitHub URL after `https://liascript.github.io/course/?`.

Keep the lesson and its simulator in separate browser tabs, side by side if you have room.

## Modules
